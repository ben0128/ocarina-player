遊戲辨識不到時，先試試換音高或改用純音。iPhone 沒有聲音的話，請關掉側邊的靜音開關。

GitHub：ben0128/ocarina-player

有 bug 或想加的功能，歡迎到 GitHub 開 issue。

按鍵是 Switch 2 的預設配置，五個音由低到高是 L R A Y X。薩爾達的搖籃曲和時之歌有任天堂官方截圖可以對照，其他歌照原版旋律換算。網頁靠聲音讓遊戲辨識，跟按鍵配置無關。

長按 icon 約 0.3 秒可以拖曳排序。釘選、順序、設定和稻草人旋律都存在這個瀏覽器裡。

非官方玩家工具，與任天堂無關。
